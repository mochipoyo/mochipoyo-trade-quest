# 自動プレイによるバランス調整

「実際に遊んだ記録をもとにしたバランス調整」は、まだ実際のプレイ記録がないため、**自動プレイ（シミュレーション）で調整**しました。あわせて、実際に遊んだ記録を集める仕組み（プレイ記録）を入れました。記録が集まったら、それをもとに調整し直せます。

- シミュレーション：`docs/tools/balance-sim.js`（ゲームのコードをそのまま読み込み、画面を使わずに動かす）
- 実際の記録の集計：`docs/tools/playlog-analyze.js`（設定 → データ管理 →「プレイ記録（バランス調整用）」で書き出した JSON）

> 注意：自動プレイの結果は、決まった規則で判断する「自動のプレイヤー」の成績です。人が遊んだときの成績とは違います。数字は調整の目安です。

## 自動のプレイヤー
| 名前 | 判断のしかた |
|---|---|
| でたらめ | ロング・ショートを半々で選ぶ |
| 見立ての向き | 判断した瞬間に見えていた足だけで作る見立て（`Market.assess`）の向きに入る。向きがなければ見送り |
| 根拠がそろう時だけ | 見立てがはっきりしていて（clarity 0.25以上）、飛び乗り・急変動でなければ入る。それ以外は見送り |
| 技の条件・流派の根拠 | その技の追加威力の条件、または流派のテーマの根拠がある向きに入る |
| 全部見送り | すべて見送る |

## A. 必殺技50種類（各技600回）
入ったときの威力の倍率の期待値（通常攻撃1回＝1.0）。

| | でたらめ | 見立ての向き | 根拠がそろう時だけ | 勝率（でたらめ／根拠） |
|---|---|---|---|---|
| 調整前 | 1.46 | 1.66 | 1.67 | 34%／38% |
| 調整後 | 1.50 | 1.84 | 1.87 | 34%／38% |

- 調整前：根拠に従っても、でたらめと差がない技が8種類あった（ボラティリティ術・資金管理・守護術・究極トレード奥義の上位の技など）
- 調整：**判断した瞬間の根拠がそろった向きに入ったとき**、利益なら威力 ×1.15（「根拠どおりの判断」）、損失なら +0.10。結果ではなく、判断の過程に少し報いる（`Ultimates.PROCESS_BONUS`・`PROCESS_LOSS_BONUS`）
- 調整後：根拠に従ったときの威力は、でたらめより平均で約2割大きい。それでも差がない技が3種類残る（深淵の波動反転 1.51／1.52、超変動破砕砲 2.23／2.38、究極奥義・相場神撃 1.48／1.52）。これらは急変動・反転の相場が多く、シミュレーション相場では見立ての当たりやすさの差がほとんどないため。**未調整のまま**（相場は確率的という方針どおり。実際のプレイ記録を見て判断する）
- 勝率そのものは変えていない（相場のシミュレーションは変更なし）

## B. 師匠の試験（各流派・各試験300回）
| | でたらめ | 根拠がそろう時だけ | 全部見送り |
|---|---|---|---|
| 調整前・初級 | 7〜35% | 100% | **66〜98%** |
| 調整前・上級 | 0〜6% | 100% | **37〜99%** |
| 調整後・初級 | 14〜37% | 76〜98% | 0% |
| 調整後・上級 | 0〜7% | 91〜100% | 0% |

- 調整前：**すべて見送るだけで、ほとんどの試験に合格できた**（根拠がそろわない場面の見送りが85点だったため）
- 調整：根拠がそろわない場面の見送り 85点→67点（今も合格点以上の「良い判断」）、根拠がそろった場面の見送り 52点→38点。合格の条件に「1問以上はエントリー」を追加（上級を2問以上にすると、慎重な判断でも3割ほど不合格になったため、初級・上級とも1問）
- 試験の結果画面に「エントリー ○問」を表示

## C. クイズモンスター
その地域のランダムエンカウント1回あたりの経験値・ゴールドと比べた報酬、正答率ごとの「倒すまでに奪われるゴールドの期待値」（所持金は上限に届く額。2万回の試行）。

| モンスター | 地域の1戦（経験値・G） | 報酬 調整前→調整後 | 正答率50%で奪われる額 | 25%（でたらめ） |
|---|---|---|---|---|
| モグラン | 9・9G | 経験値60→**90**・80G→**100G** | 約95G | 約260G |
| ミラグ | 34・18G | 経験値250・200G→**300G** | 約275G | 約720G |
| ガルゾ | 196・37G | 経験値1200・600G→**800G** | 約730G | 約1,840G |
| ゼルキス | 613・54G | 経験値4000・1500G（変更なし） | 約1,350G | 約3,290G |
| アルカディア | 2028・112G | 経験値9000・4000G（変更なし） | 約2,620G | 約6,190G |

- 経験値：その地域で想定するレベルのおよそ1〜1.5レベル分にそろえた（モグランだけ低かったので上げた）
- ゴールド：正答率50%の人が倒すまでに奪われる額の期待値（およそ上限）を下回らないようにした
- 損失率・上限は指示どおり（変更なし）

## プレイ記録（実際の記録を集める）
- 設定 → データ管理 →「プレイ記録（バランス調整用）」：件数の確認・JSON で書き出す・記録を止める・消す
- この端末のブラウザの中だけに保存（専用のキー `mochipoyo_playlog_v1`。セーブデータとは別。どこにも送らない）。最大1500件
- 記録するもの：戦闘の結果、必殺技の結果と威力、チャートの判断（修行・試験・戦闘）、試験の結果、クイズモンスターの正誤と奪われた額、はじめて入ったマップ（そのときのレベル・所持金）
- 書き出した JSON を `node docs/tools/playlog-analyze.js ファイル.json` で集計できる。次の調整では、実際の勝率・合格率・正答率・進み方を見て、この文書の数字を見直す
