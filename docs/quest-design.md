# クエスト設計（quest-design）

既存：main_1〜main_4、sub_bandit、learn_pullback / learn_range / learn_hidden / learn_stoploss、師匠の特別クエスト mq_eye / mq_env / mq_discipline / mq_master（維持）。
クエストはすべて `State.data.quests[id] = { state: 'active'|'done' }` と `flags` で管理し、報酬は `Events.questComplete` で1回だけ付与する（二重加算なし）。
実装状況：**【今回実装】**（v5.0）／**【データのみ】**（QUESTS に定義、開始NPCは未配置）／**【未着手】**。

### エンディング分岐条件
- 選択（破壊／再設計）を基本とし、仲間の信頼度（会話イベント達成数）と各地の復興度（verum_liberated、sentra_reform、aruna_lit、zeromea_choice）でエピローグの各地の描写が変わる
- 「新しい均衡」は、第6章・第12章で「権限の制限と監査」を選んでいた場合にのみ選択肢として提示される（そうでなければ A のみ）
