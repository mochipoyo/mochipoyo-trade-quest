# トレード学習と物語の統合（trade-learning-integration）

## 1. 原則
- 教育内容は「もちぽよ手法」の範囲：日足・4H環境認識、1H確認、15m/5mエントリー、ダウ理論と波形、EMA20/30/40、RCI9 ±70反転、MACD(6,13,4)、通常・ヒドゥンダイバージェンス、複数根拠の整合、RR1:1.5〜3、損切りと適切なロット、無理なエントリーや飛び乗りの回避。必勝法として扱わず、未指定の細部は確定しない
- 物語とトレード学習を無理に同一視しない。地域で学ぶ「考え方」をチャート分析へ応用できるように、学習イベントの前後で師匠の言葉として橋渡しする
- チャート学習は通常戦闘と分離（既存どおり）。重要イベント・修行場・石碑で使う
- 初心者が学習問題に何度か失敗してもストーリーが進行不能にならない：必修イベントは「2回失敗で合格点50、4回で40」（既存）、さらにメインクエストの進行フラグは学習イベントの合格を**要求しない**（ヴェルムの資金管理の試練は main_5 の必須条件に含めない）

### v5.6 で追加した学習の連動
- 相場の試練を使うボス：記憶庫の番人（whipsaw / false_breakdown / rci_cold_trend）、凍結の時計守（mtf_conflict_up / reversal_confirmed_down / div_bear_against_htf）、幽霊船長（jump_in / bad_rr / false_breakout。「値下がりを恐れて嵐の日に出航した」船長＝恐怖による飛び乗り）、旧都市の演算核（whipsaw / div_against_htf / mtf_conflict / bad_rr_sell）。既存どおり「有利になる」方向のみ
- ルシアの個別クエスト lucia_wave：鐘都の波読みの老人の試練（whipsaw / div_against_htf / mtf_conflict / reversal_confirmed_up、60点以上で合格。失敗しても再挑戦できる）
- 師匠の特別クエスト A「達人の眼」（90点以上6回・分析5項目すべて正解10回・上位足に逆らうダイバージェンスの見送り2回）／S「導師の証」（異なる30場面で正解・ヒントなし正解40回・90点以上12回）。ランクA／Sで解放
- サブクエストの題材：パン一つの税（税の計算の誤りを示す）、最初の監査（帳簿の合わない一行を選ぶ）、市場の再開（貸したお金が返るのは町が立ち直ってから）。いずれも現実の投資の利益を示すものではなく、記録と検証の考え方を物語にしたもの

## 3. 学習とRPGの連動（既存の仕組みを維持）
- 必修イベント達成＋分野の理解度 → 特殊能力（ダウの眼／EMAの加護／RCIリバーサル／MACDヒドゥンストライク／上位足の眼／損切りシールド／忍耐の構え）
- トレーダーランク（F〜S）→ 称号・報酬・師匠の特別クエスト・隠し部屋・能力
- 第5章以降の追加：
  - ヴェルムの「灰の洞窟」（隠し）はランクC扉
  - 第6章の監察官リーヴはランクC以上で主人公の帳簿分析を信用する（会話分岐、進行必須ではない）
  - 最終決戦で、習得した学習能力がボスの各段階（恐怖／欲望／固定）に対する有効な手段になる（ダウの眼＝固定段階の防御崩し、損切りシールド＝欲望段階の大ダメージ軽減）

- 既存34本（初級8・中級15・上級11）は維持。生成は v4.4 の乱数モデル

- 追加時は `js/data/scenarios-extra.js` に定義し、`scratchpad/genseeds.js` で検証済みシードを再生成する

## 5. 詰まない設計（再掲）
- 必修学習イベントの合格点緩和（60→50→40）、教えの読み返し、3段階ヒント
- メインクエストの必須条件に学習イベントの合格を含めない（学習は能力・称号・隠し要素の鍵）
- ボス戦の学習連動は「有利になる」方向のみ（能力がなくても倒せる難易度）
