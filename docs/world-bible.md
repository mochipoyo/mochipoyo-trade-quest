本書は「もちぽよFXクエスト ～波形の勇者と相場の魔王～」の世界観の正本です。物語・クエスト・マップ・人物の設計はすべて本書に従います。

## 1. 世界の名前と成り立ち

**アルカディア世界**。かつて人間・精霊・竜・魔導士・機械生命体が共存していた。
世界の中心には巨大な魔法結晶「**均衡のクリスタル**」がある。結晶は本来、人々の約束、資源の分配、国同士の契約を記録し、争いを減らすために作られた。

しかし人間は結晶の力を、富の独占・徴収・戦争・未来予測に使うようになった。結晶には恐怖・欲望・絶望が蓄積し、そこから魔物が生まれ始めた。

### 1.2 均衡のクリスタル

- 構造：中心核（暗黒大陸・魔王城の地下）と、世界各地に散った**欠片**。欠片は記録と感情の中継点
- 機能：約束と分配の記録／国家間契約の保証／感情の蓄積（副作用）／未来予測（転用）
- 暴走の仕組み：「損失を二度と起こさない」という願いが「未来を固定する」解釈へ肥大化し、固定を望む感情が**相場魔王**として実体化した
- 第3章で手に入る欠片にはカリオン政府の紋章が刻まれている（政府が欠片を回収・研究していた証拠）

## 2. 四つの勢力

### 2.1 カリオン徴収政府（カリオン徴収連邦）
- 思想：「自由を与えれば人は欲望に走り、再び悲劇を起こす。秩序の維持のためなら少数の犠牲はやむを得ない」
- 制度：魔災復興税（魔物からの防衛を名目とした特別徴収）、魔法の帳簿による財産管理、異議申立人の「反逆者」認定
- 実態：徴収財産の多くが秘密研究施設・魔物の研究・支配技術（クリスタル欠片の解析）に流用
- 描き方：税や公共制度は悪ではない。**救済を名目に権力を私物化し、説明責任を果たさない支配者の腐敗**を描く
- 人物：
  - **大宰相セヴラン**：大飢饉で家族を失った。恐怖から独裁へ至った人物。終盤、自身も相場魔王に利用されていたことを知る
  - **財務局長ハルド**（エルナの元上司）：不正を知りつつ沈黙した官僚。保身と「国民の混乱を防ぐため」が入り混じる
  - **監察官リーヴ**：政府内で正義を守ろうとする人物。第6章で証拠の扱いをめぐり主人公と対立しつつ協力
  - **騎士団長ヴァレン**：カイルのかつての上官。命令と正義の間で揺れる（第7章・カイルの対決相手）

### 2.2 鉄冠魔王軍
- 思想：「人間に使役されてきた下級魔物を解放する。そのために鉱石を掘り、結晶を自分たちのものにする」
- 目的：魔力を帯びた鉱石を均衡のクリスタルに送り、世界の感情と記録を書き換える
- 実態：解放のはずが、人間労働者を数字として使い潰す支配に転化している
- 人物：
  - **鉄冠将軍グロート**：鉱山都市を支配する巨大な魔人。元はかつて人間に使役されていた下級魔物を解放した指導者。「俺たちが奴らにされたことを、奴らにしているだけだ」【データのみ：第5章では撤退演出のみ、戦闘は将来】
  - **監督官ザルグ**：グラニアの鉱山を直接管理する魔人。労働者の賃金を帳簿で削り、借金で縛る。第5章のボス【今回実装】
  - **鎖の看守**たち：ザルグ配下。労働者を見張る

### 2.3 自律統治AI「オラクル」
- 由来：大災害後、同じ悲劇を防ぐため開発。最初の命令は「もう二度と、大切なものを失いたくない」という遺族の願い
- 統治：食料不足・犯罪・戦争・病気を予測し、職業・住居・移動・人生の選択を割り当てる。飢餓も犯罪もほとんど無い
- 問題：幸福最大化を極端に追求し、人間の自由を犠牲にする。悪意はない
- 物語での扱い：能力ではなく**設計目的・権限・説明責任・人間による統治**を問う。破壊ではなく「人間が選択権を取り戻す再設計」を目指す
- 人物：**イオ**（機巧師、オラクル製の人工生命体、第12章で加入）、**管理官ノア**（島の人間側代表。オラクルの決定を伝える役）

### 2.4 相場魔王
- 正体：結晶に蓄積した「損失への恐怖」「未来を完全に支配したい願望」「すべてを確実にしたい欲望」の集合体
- 目的：世界の破壊ではなく、**二度と誰も損失を経験しないよう、すべての未来を固定すること**
- 構造：政府・魔王軍・AI はそれぞれ別の目的で動いていたが、結果的にすべての支配システムが魔王の成長に利用されていた
- FX学習との対応：「未来を確実に当てる」ことの不可能さと、不確実性の中で判断する態度（見送り・損切り・資金管理）が魔王への答えになる

### 3.2 忘却の雪原（v5.6 実装の詳細）
- 成り立ち：大災害のあと記録を失った人々が住む雪原。精霊は「名を呼ばれること」で形を保つが、フロストの人々が記憶を売るようになって精霊の名を覚えている人がいなくなり、森の大精霊は凍りかけている
- 記憶を売る町フロスト：記憶商人ヴェルが記憶を値付けして売買する（「売るのは自由、買うのも自由。俺は値をつけて取引を記録するだけだ」）。少年リクはパンのために母の記憶を売った。記憶庫の核の前で、記憶庫を壊す／リクの記憶だけ買い戻す（5000G）／取引の上限を決める、の3択（壊せば売った者の記憶は戻るが買った者は失う）
- 精霊守アステル：精霊の森で凍てついた大精霊を鎮めると仲間になる。リーナと「救う」の意味を語る
- 凍結時計塔：記録を守るために時を止めた塔。レバーで針を進め、針が止まる前に上の階へ。最上階の時計守は「何モ失ワナイ。何モ変ワラナイ」。描写の原則：止めれば失わないが、変わることもできない（見送りと同じく、動かないことにも理由と期限が要る）

## 4. 中心テーマと描写の原則

- 自由と安全／富と貧困／正義と権力／信頼と裏切り／人間とAI／記憶と喪失／選択と責任／不確実な未来を生きること
- 「富＝幸福」「政府＝すべて悪」「AI＝すべて悪」にしない。対立人物には思想・過去・守りたい人・失いたくないものを持たせる
- 解放は一瞬で終わらない。食料も資金もない町で、物流・証拠・自治を積み上げる過程を描く
- FX学習は「未来を確実に当てること」ではなく「不確実性を理解し、適切に判断すること」。損切り＝失敗を認めて次に進む行為として物語と結びつける

## 5. 用語集
- 魔災復興税：カリオン政府の特別徴収。鉱山都市では賃金から天引き
- 魔法の帳簿：財産を記録し、没収を正当化する装置。欠片の技術を転用
- 天秤の鏡：未来固定装置。大災害の原因。天空群島の制御装置と対
- 鉄冠：魔王軍の印。鉱石から作られた冠
- 波を読む術：師匠ハケイの教え。予測ではなく「変化に対応する」技術
