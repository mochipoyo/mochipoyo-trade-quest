# 人物設定（characters）

実装状況：**【実装済】**／**【今回実装】**（v5.0）／**【データのみ】**／**【未着手】**。既存の仲間ID（lina, kyle, mina, seris, gald, lucia）と加入条件は維持する。

## 1. 主人公
- 名前はプレイヤー入力（既定「勇者」）。ポヨ村で目覚めた記憶の曖昧な旅人。職業は初期選択（戦士・魔法使い・僧侶・武闘家・盗賊・商人・狩人のいずれか）
- 物語上の役割：「波を読む術」を学び、不確実な未来の中で選ぶ人。結末で「みんなが自分の世界を守れるようになっただけ」と言う
- 成長：トレーダーランク（F〜S）と称号（Phase 3実装）が物語の信頼度にも影響する（第6章以降、ランクCで監察官リーヴが信用する等。【データのみ】）

## 2. 師匠ハケイ
- ポヨ村の修行場の師。かつて断裂群島の災害を生き延び、「未来を当てる術」ではなく「変化に対応する術」として波を読む技術を体系化した
- 各章の学習イベントで教えを与える。第5章では手紙で「損を認めて切る者だけが次の波に乗れる」と資金管理を説く【今回実装】
- 第10章で、彼自身が「天秤の鏡」の予測に頼り家族を失った過去が明かされる【データのみ】

## 3. 既存の仲間6人（成長イベント）
各仲間：会話イベント3〜5（キャンプ／酒場／拠点で発生、フラグ管理）＋個別クエスト＋エンディング後。

### リーナ（lina・僧侶）【実装済／イベントは今回一部実装】
- 新ストーリー：貧しい人々を救う医療・救済活動に関わる。資金も時間も足りない現実に苦しむ
- 会話イベント：①ヴェルムの配給所で病人を診る（第5章）【今回実装】 ②カリオンのスラムで「薬は誰に配るべきか」 ③灰灯島の老人の看病 ④ゼロメアで「病気のない島」を見て揺れる ⑤最終決戦前「救えなかった人の分まで」
- 個別クエスト lina_clinic（第6章）：スラムの診療所を開く。薬の仕入れ先を交渉
- エンディング後：ヴェルムとカリオンを巡回する医療隊を組織する

### カイル（kyle・騎士）【実装済】
- 新ストーリー：政府の命令に従うことと正しいことの違いに向き合う。騎士団の元仲間との対決
- 会話イベント：①迷いの森の祠で部下の話（第2章・既存を拡張） ②ヴェルムで看守を見て「俺も命令で人を縛ったことがある」【今回実装】 ③カリオンで元同僚と再会 ④王都でヴァレン団長と対峙前夜 ⑤「騎士の誓いは王にではなく民に」
- 個別クエスト kyle_oath（第7章）：ヴァレン騎士団長との一騎打ち。勝利後、団長は王宮の門を開く
- エンディング後：新しい騎士団の規範を作る

### ミナ（mina・盗賊）【実装済】
- 新ストーリー：失踪した父親の秘密を追う。海底都市で父の最後の記録を発見
- 会話イベント：①ダウの村で父の話（第2章） ②マリナで「海の向こうに父の手がかりがある気がする」【今回実装】 ③灰灯島で父の名を知る人に会う ④海底の図書館で記録を読む前夜 ⑤記録を読んだ後
- 個別クエスト mina_father（第9章）【v5.2 実装】：ミナ同行で海底都市に着くと開始。封印区画で父ダリルの最後の記録を読むと達成（鍵は司書の残像から）
- エンディング後：記憶の図書館の司書になる

### セリス（seris・魔法使い）【実装済】
- 新ストーリー：AIと魔導技術の起源を調べる。師テオドルの研究が支配システムにつながっていたことに葛藤
- 会話イベント：①忘却の洞窟の欠片を調べる ②ヴェルムで鉱石が結晶へ送られていると知る【今回実装】 ③ゼロメアでオラクルの基礎理論に師の名を見る ④マクディアで師の手記 ⑤「技術を止めるのではなく、責任の形を決める」
- 個別クエスト seris_master（第13章）：禁書庫で師の最後の手記を回収
- エンディング後：魔導と機械の共同監査機関の設立に関わる

### ガルド（gald・戦士）【実装済／今回実装：第5章イベント】
- 新ストーリー：鉱山都市の過去に向き合う。かつて救えなかった労働者たちと再会
- 会話イベント：①マリナ酒場「俺は海の向こうの出身だ」（第4章）【今回実装】 ②ヴェルム上陸時「町が煙の下にある」【今回実装】 ③宿舎での告白（gald_confession）【今回実装】 ④ザルグ撃破後、地下の集会所でハルトに「おれの手を使ってくれ」と申し出る【今回実装】 ⑤自治会設立後「今度は残る」【今回実装】
- 個別クエスト gald_reunion（第5章）【今回実装】：ヴェルム解放後、ガルドをパーティーに入れて労働者の宿舎を訪ね、かつての部下ベルクと向き合う。ガルドは「守るために従ったつもりだった」と告白し、ベルクは「許すかどうかではなく、これからは自分で決める」と答える。プレイヤーの選択（ガルドの言葉を待つ／ベルクにガルドが戦った理由を伝える）で台詞が変わる。報酬：経験値300・戦斧（battle_axe）。フラグ gald_confession
- エンディング後：ヴェルムの鉱夫組合長

### ルシア（lucia・波形剣士）【実装済】
- 新ストーリー：「波を読む技術」の本当の意味を理解していく。予測より変化への対応
- 会話イベント：①修行場で師匠の過去を問う ②ヴェルムで「帳簿の数字は未来を保証しない」【今回実装】 ③時の神殿で未来を見て動揺 ④ソフィアと「見える未来と選ぶ未来」 ⑤魔王城前「読むのは波で、決めるのは自分」
- 個別クエスト lucia_wave（第10章）：神殿の試練をヒントなしで越える
- エンディング後：修行場を継ぐ

## 5. 敵対人物
- **大宰相セヴラン**：第7章の対決相手（直接戦闘は親衛隊＋魔法帳簿の守護機構。本人は失脚）。第15章で再会し、自分の選択の結果と向き合う。恐怖から独裁へ至った人物として描き、最後は「私は、飢えを二度と見たくなかっただけだ」と言う
- **財務局長ハルド**：エルナの元上司。保身と「混乱を防ぐため」が混じる。第6章の地下記録庫で対峙（中ボス：帳簿の守護者を召喚）
- **騎士団長ヴァレン**：カイルの元上官。第7章で一騎打ち。敗北後、王宮の門を開く
- **監督官ザルグ**（boss_overseer）【今回実装】：ヴェルムの魔人。「労働者は数字だ。数字は嘘をつかない」。帳簿で賃金を削り借金で縛る。鉱山最深部で戦闘。撃破後、帳簿の切れ端が散らばる
- **鉄冠将軍グロート**（boss_grote／再戦は boss_grote_2）【v5.4 実装】：第5章では撤退演出。かつて下級魔物を解放した指導者。第15章で魔王城の門を守り、敗れたあと鉄の冠を託す
- **オラクル**：第12章。戦闘ではなく「統治再設計」の対話と、防衛機構との戦い
- **相場魔王**【v5.4 実装】：第16章。最終決戦（3段階：恐怖／欲望／固定。各段階で戦闘中にチャートの試練）。倒すことは願いを「固定」から解き放つこと
