## 4. 効果の実装先（ロジック）
- `js/rpg/combat.js`：ダメージ計算に装備の `onDamage`（軽減・分散）、`onDefend`（MP回復、次ターン強化）、`hits`（多段）、`onHit`（素早さ低下）、`guardFatal`（お守り）を追加。既存装備と重複しない役割にする
- `js/rpg/actors.js`：`Actors.stats` に装備の passive（agi/mag 加算は既存の `agi`/`mag` 項で対応済み）
- `js/ui/minimap.js`：compass_wave / glasses_htf / 測量士パッシブは探索範囲・隠し表示に反映
- v5.5（Phase 7-1）：トレード装備20種の効果ロジック（`js/rpg/combat.js` の fx）と入手場所を実装（見送りの首飾りの入手のみ 7-2）。竜炎火山群島の鍛冶街イグナスで、トレード武器6種を竜の鱗1枚＋3000Gで強化版（_2）に鍛え直せる。v5.0（Phase 1〜2）では未着手
- v5.6（Phase 7-2）：見送りの首飾りの入手（記憶を売る町）、精霊守と7職の高位スキル（Lv20／Lv25）、精霊守の特性（`combat.js` の敵の魔法の計算）と「魔法への耐性」の強化（buff キー `mres`）、v5.6 の通常装備14種
