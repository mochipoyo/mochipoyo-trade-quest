- **技術的な完成：Phase 1 の範囲では完了**（下の §21 チェックリストで自動テストにより確認。ただし実機での確認は未実施）

| セーブ移行テスト（migrate.js） | 第1〜16章の進行を模したセーブ16件（章ごとにレベル・仲間・クエスト・フラグ・乗り物・所持品・トレード成績・場所を設定）を2D版の枠に置き、3D版で取り込み → 開始 | 16件すべて：取り込んだ内容は2D版が同じセーブを読み込んだ結果と一致、開始できる、2D版のセーブは不変 |

**セーブ移行について（注意）**：使ったのは「章ごとの進行状況を模して作ったセーブ」で、実際に第1〜16章を遊んだセーブではありません。主人公の項目は、2D版の読み込み処理（`State.migrate`）が行う正規化（例：職業レベルの欄の補完）だけ差が出ます。これは2D版で読み込んだときと同じ結果です。マップ座標は2D版と3D版で同じ（1タイル＝1単位）なので、座標の変換は不要です（変換規則＝そのまま）。

### 2D版の回帰テスト

| スイート | 結果（state.js 変更後） |
|---|---|
| maptest・enemytest・assettest・tradeeq・tradetest・growthtest・learntest・playtest・ch5test・ch67test・ch89test・ch17test・skill56 | 1回目でエラー0 |
| ch1012test（第10〜12章） | 1回目：ボス「コア防衛機構」に自動戦闘で敗北して失敗 → 再実行2回はどちらもエラー0 |
| ch18test（忘却の雪原） | 1回目：ボス「時計塔の番人」に自動戦闘で敗北して失敗 → 再実行はエラー0 |
| ch1316test（第13〜16章） | 4回中2回エラー0、2回は魔王城の自動戦闘で敗北して失敗 |

**失敗の原因の切り分け**：失敗はすべて「テストの自動戦闘（攻撃ボタンを押し続けるだけ）でボスに負けた」ことによるものです。同じテストを **変更前の state.js（2D版 v5.6 のまま）** でも実行したところ、ch1316test は4回中1回、同じ敗北（恐怖の魔物）で同じ失敗になりました（ch18test は変更前で1回実行しエラー0）。state.js の変更は2D版では保存先の文字列を変えないので戦闘に関係せず、失敗は以前からある **乱数による不安定なテスト** と判断しています（推測を含みます：乱数の偏りか、同時に重いテストを動かしていたことによるタイミングの影響かは切り分けていません）。

## 6. 美術的な評価（依頼書 §17 の10項目。参考画像との比較）

評価：◎ 参考画像の水準に近い／○ 方向性は合っている／△ 不十分

| 項目 | 評価 | コメント |
|---|---|---|
| 1. 建物の立体感 | ○ | 箱ではなく、土台・木組み・せり出し・板瓦・破風・ドーマー・窓まわりまで作り込み。ただし壁の汚れ・苔・屋根のたわみなどの「経年感」が無く、参考画像より整いすぎている |
| 2. 地形の自然さ | ○ | 石畳と土と草の境界をノイズで崩し、外周は丘と山へ。村の中は平らで、段差・坂・水辺がない |
| 3. キャラクターの造形 | △ | 平面の板ではなく骨とアニメーションのある3Dモデル。ただし頭身の低い簡素な造形で、顔・髪・服の作り込みは参考画像に遠く及ばない |
| 4. カメラアングル | ○ | 48°（既定）・38°・56°を比較して選択。建物の陰では主人公のまわりを抜く表示＋シルエット |
| 5. 照明 | ○ | 時間帯で空・太陽・霧・窓明かりが変わる。夜は街灯と窓が灯り、ブルームでにじむ（参考画像の夜景の方向） |
| 6. 影 | ○ | 太陽の影（高画質 2048）と足元の丸い影。屋内の点光源は影を落とさない |
| 7. 色彩 | ○ | 暖色の村と寒色の夜。草の色むら・屋根の色分け。全体に少し彩度が低い場面がある |
| 8. 町の密度 | △ | 街灯・ベンチ・樽・花壇・柵・畑・井戸・看板はあるが、参考画像に比べて小物・植木鉢・吊り花・露店・人の数が少ない |
| 9. 世界観の統一 | ○ | 木組みの村・板瓦・石畳・ランタンで統一。修行場の幟・人工チャートの掲示板でトレード要素も表現 |
| 10. 実際に歩いたときの没入感 | △ | 走る・歩くのアニメーション、草の揺れ、煙、舞う粒、蛍。ただし足音・環境音・カメラの揺れはなく、**実機の操作感は未確認** |
