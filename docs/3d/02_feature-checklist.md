# 機能互換チェックリスト（2D版 v5.6 → 3D版 Phase 1）

凡例：
- **3D** … 3D版で3D表示・3D操作になっている
- **継承** … 2D版のコードがそのまま動く（画面は3Dの上に重なる、または2D表示）
- **2D表示** … 3D版の中でも従来の2D画面で動く（Phase 2 以降で3D化）
- **未** … 未実装
- 確認方法：自動テスト＝Playwright（Chromium・ソフトウェア描画）での自動確認、目視＝画面写真での確認。**実機（GPU つき PC・スマホ）での確認はまだ行っていません。**
