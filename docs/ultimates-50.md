# 必殺技50種類・トレーダー師匠10人・リアルタイムのチャート戦闘

この文書は、主人公の「必殺技」（50種類）、各地の「トレーダー師匠」（10人）の修行・試験、必殺技を使うと開く「いま動くチャート」について、実装した内容・確認した方法・確認できていない点をまとめたものです。

- 相場はすべて **架空のシミュレーション相場**（架空ペア POYO/MOCHI）です。画面にも「シミュレーション相場」と表示します。実在の銘柄・実際の値動き・将来の値動きを示すものではありません。
- 必殺技を使えるのは **主人公だけ** です（判断はプレイヤー自身がするため）。仲間・敵・オート戦闘は使いません。
- 既存のストーリー・クエスト・キャラクター・職業・装備・アイテム・モンスター・呪文・特技・トレード機能は削除・変更していません（戦闘のコマンドとメニューに項目を足し、マップに NPC を足しただけ）。

## 2. 取引と威力のきまり

- チャートを開くと、過去の足を48本（ズームで30〜120本）表示し、判断している間も足ができていく（初期は12秒。設定で8・12・16・20・30秒）。時間切れは見送り。
- 選べるのは **ロング（買い）／ショート（売り）／見送り** の1回だけ。連打しても最初の1回だけを受け付ける。エントリーは選んだ瞬間の価格（ロング＝買値、ショート＝売値。スプレッド0.6pips＋入口のスリッページ0〜0.2pips）。
- 損切り＝ATR×1.0、利確＝ATR×1.8、最大保有＝12本（時間切れ決済）。ATR はエントリーした時点で確定していた足の ATR(14)。
- 判定はティック（1本＝8ティック）の順番。ティックの間も価格は連続して動くとみなし、損切りは損切り価格から0.3pips不利に約定。1ティックで ATR×1.0 より大きく飛んだ急変で損切りを飛び越えたときだけ、そのティックの価格で約定（さらに不利）。ティックの道筋がないとき（OHLC だけ）は、同じ足で両方に届いたら損切りが先（保守的）。
- 損益は決済価格と約定価格の差（スプレッド・スリッページ込み）。損益÷ATR の絶対値が0.15未満は「ほぼ同値」。
- 威力（通常攻撃に対する倍率）：
  - 利益：技ごとの範囲（全体で2.5〜4.5倍）。利確に近いほど大きい（損益÷ATR が0.15で最小、1.8で最大）。判断した時点の相場の状態が技の条件に合えば「追加威力」を掛ける（上限4.5倍）。
  - 損失：技ごとの範囲（全体で0.2〜0.5倍）。小さな損ほど大きく、損切りまで行くと最小。
  - ほぼ同値：0.6〜0.75倍（技ごと）。
  - 見送り：ダメージなし・防御（被ダメージ半減）。見送りが適切だった（根拠がそろっていない・はっきりしない・飛び乗りになる・急変動の最中）ときは、使った MP の半分が戻る。見送り専門の技（偽突破看破・偽りの突破封じ・冷静なる撤退・完全見送りの結界）は、適切な見送りで味方全体の守りや MP の全額返還（1戦闘に1回）。どの場合も MP が増えることはない。
- 追加効果（連撃・全体・防御無視・ボスに強い・敵の弱体・味方の強化・回復など）は利益のときだけ。損失のときの守り（guardOnLoss）・損失の下限（lossFloor）は損失のときだけ。
- クールダウン：技ごとに1〜5ターン（戦闘ごと。セーブしない）。MP は2〜16。

## 5. 修行場と試験

- 初めて話すと、自己紹介・流派の紹介・次の師匠の場所のうわさ。メニュー：流派の話・初心者向けの説明・チャート修行・初級試験・上級試験・流派の技・成績。
- チャート修行：何度でもできる。難しさを3段階から選ぶ。記録（回数・成績）だけ残り、報酬はない。
- 初級試験：5問。受けられる条件＝技①の習得レベル以上。合格＝平均60点以上、かつ「根拠のそろった向きと逆に入った」判断が1問まで。
- 上級試験：10問。条件＝初級合格＋技③の習得レベル以上。判断のあとに理由（7つから）も選ぶ。合格＝平均65点以上、かつ無謀な判断（流れに逆らう・飛び乗り）が2問まで。
- 採点（`Ultimates.score`）：正解は一つではない前提で、**判断の過程（0〜60）**・**結果（0〜25。負けても過程が良ければ合格できる）**・**理由（0〜15。上級だけ）** に分けます。過程は、判断した瞬間の見立て（`Market.assess`）と比べ、その流派のテーマの根拠（例：ダイバージェンス術なら逆行・RCI の反転）に沿った逆張りは高く、根拠のない逆張り・飛び乗り・急変動中のエントリーは低くします。はっきりしない場面の見送りは高得点、時間切れの見送りは少し減点。
- 合格で技を覚えるのは1回だけ（何度合格しても増えない）。試験の記録は全問を終えたときにまとめて書きます（途中で中断・再読み込みしても記録は残らない）。
- 判断のあとに「判断した瞬間に見えていた状態（簡易的な見立て。正解ではありません）」を表示します。判断の前には出しません（答えのヒントにならないように）。

## 7. 戦闘への組み込み

1. 主人公のコマンドに「必殺技」（「じゅもん・とくぎ」の次）。まだ覚えていなければ選べない（レベル2で最初の技）。選ぶと、覚えた技の一覧（MP・待ち時間・説明。使えない理由も表示）。
2. 技を選ぶ → 対象（敵全体の技は選ばない）→ 初めて使う技は説明 → チャートを開く（戦闘の HUD は隠す）。
3. 判断して決済まで進むと結果（損益・威力・見立て）を表示。「次へ」で戦闘に戻る。この時点では HP も MP も変わらない（クールダウンだけ決まる）。
4. ほかの仲間のコマンド入力。「戻る」で主人公まで戻ろうとしても、必殺技の判断は取り消せない（同じターンにチャートを引き直せない）。
5. ターンの実行：必殺技はそのターンの最初に出る（見送りの防御もそのターンの敵の攻撃に間に合う）。MP はここで1回だけ使う。名前の帯 → 既存の演出（FX65）→ 命中の瞬間に数字と HP。倒した敵には当てない（単体の技は次の敵へ、全体の技は止まる）。同じターンに2回は出ない。
6. 眠り・麻痺・混乱のときは選べない。オート戦闘では使わない。勝利のリザルト画面で、レベルで覚えた必殺技を知らせる。
- 3D 版：チャートは同じ HTML の画面を重ねる。チャートを開いている間は、下の戦闘画面（3D の舞台を含む）を1秒に1回だけ描く。師匠のいるマップは 3D 化されていない（2D 表示）。
