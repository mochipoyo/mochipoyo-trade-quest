# もちぽよFXクエスト ～波形の勇者と相場の魔王～

昔ながらの16bit JRPG風に冒険しながら、FXトレードの「判断」を学べるブラウザゲームです。
HTML / CSS / Vanilla JavaScript / Canvas だけで動作し、ビルド・サーバー・外部CDN・外部APIは一切不要です。

- 公開URL（想定）: https://mochipoyo.github.io/mochipoyo-trade-quest/
- ゲーム内のチャートは **すべて学習用の人工データ** です。実際の市場データではありません。
- セーブデータはブラウザの LocalStorage に自動保存されます。

---

## 1. GitHub Pages で公開する手順

### ① リポジトリを作る
GitHub で新しいリポジトリ `mochipoyo-trade-quest` を作成します（Public）。

### ② ファイルをアップロードする
**ZIPを展開した中身**（`index.html` などのファイルとフォルダ）を、リポジトリの `main` ブランチ直下にそのままアップロードします。

```
mochipoyo-trade-quest/
├── index.html
├── styles.css
├── README.md
├── .nojekyll
└── js/
    ├── config.js      … EMA/RCI/MACD/リスクなどの設定値（ここだけ変えれば調整可能）
    ├── indicators.js  … EMA・RCI・MACD・ZigZag・ダウ理論・ダイバージェンスの計算
    ├── scenarios.js   … 学習シナリオ（固定シードの人工データ、検証つき）
    ├── battle.js      … トレード判定（採点）・値動き再生・成績集計
    ├── data.js        … ストーリー・教材・練習問題・敵・アイテム・実績・用語辞典
    ├── sprites.js     … ドット絵スプライト（オリジナル）
    ├── chart.js       … チャート描画（Canvas 2D）
    ├── save.js        … セーブ（LocalStorage）・エクスポート・インポート
    ├── game.js        … ゲームの状態管理・進行・戦闘ロジック
    └── ui.js          … 画面描画・演出・操作
```

※ ZIP ファイルそのものを置くのではなく、展開した中身をアップロードしてください。
※ GitHub のWeb画面から「Add file → Upload files」でドラッグ＆ドロップできます（`js` フォルダごとドロップすればフォルダ構造が保たれます）。
※ `.nojekyll` は隠しファイルです。Web画面でアップロードしにくい場合は、リポジトリで「Add file → Create new file」→ ファイル名に `.nojekyll` と入力して空のまま Commit してください（無くても動作しますが、置いておくと安全です）。

### ③ GitHub Pages を有効にする（初回のみ）
リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**

数分待つと `https://<ユーザー名>.github.io/mochipoyo-trade-quest/` で公開されます。

## 2. 公開後の動作確認

1. URLを開くとタイトル画面が表示される
2. 「はじめから」→ キャラクターを選び「冒険に出る」→ ワールドマップに移動できる
3. 「始まりの村」→ 村長と話す／教えを学ぶ／実例チャート／練習問題が動く
4. 「ようすみスライムと戦う」→ チャートが表示され、時間足ボタンで切り替わる
5. 「上位足を確認」「インジケーター確認」→ 文章で状態が表示される
6. 「買い」→ 注文設定 → 「エントリー確定」→ 値動きが進み、評価が表示される
7. 勝利後、ブラウザを再読み込みして「つづきから」で続きが遊べる（オートセーブ）
8. スマートフォン（iPhone Safari / Android Chrome）でタップ操作できる

## 3. 実装済み機能

- タイトル／キャラクター選択（剣士・魔法使い・賢者、見た目と初期ステータスが違う。正解判定は同じ）
- ワールドマップ（8エリア、順番に解放）
- 各章：NPC会話 → 教え（5項目前後）→ 実例チャート → 練習問題（3〜4問）→ モンスター戦 → ボス戦 → 復習 → クエスト達成
- チャートバトル：買い／売り／見送り／上位足を確認／インジケーター確認／損切り・利確設定／ヒント／アイテム／撤退
- チャート描画：ローソク足・EMA20/30/40・RCI(9)・MACD(6,13,4)・ZigZag（確定済みは実線、未確定は点線）・直近高値安値・損切り/利確/エントリーライン・時間足切替（5分/15分/1時間/4時間/日足）・拡大縮小・全画面表示
- 14種類の学習シナリオ（上昇/下降トレンド、押し目/戻り、ヒドゥン/通常ダイバージェンス、レンジ、ダマシのブレイク、上位足不一致、リスクリワード不良、飛び乗り、RCI過熱での逆張り禁止）
- 各シナリオは固定シードの5分足から全時間足を集約生成（MTF整合）。生成後に自動検証（check）し、想定どおりの状態でない乱数は採用しない
- 判断プロセスの採点（上位足確認・インジケーター確認・方向/波形/見送り判断・損切り位置・リスクリワード・資金管理）、ルール違反の分類
- エントリー確定後に未来の足を1本ずつ進めて判定（判断時点では未来情報を使わない）。同一足で利確と損切りの両方に到達した場合は保守的に損切り扱い
- 正しい判断でも損切りになる／悪い判断でも偶然利益になる、を結果画面で明示
- レベル・経験値・HP/MP・分析力/判断力/忍耐力/資金管理力・総合トレーダーランク（利益額ではなく判断の質で決定）
- アイテム（ポーション/エーテル）と装備（章クリア報酬。補助能力のみで正解判定は変えない）
- 実績・称号（13種類）、トレード成績（勝率・平均損益・平均RR・最大DD・見送り回数・違反回数・学習スコア）
- 用語辞典（28語）
- エンドレスダンジョン（ストーリークリア後。検証済みシナリオを別シードで出題）
- セーブ：LocalStorageへオートセーブ、JSONエクスポート／インポート、初期化
- 効果音（WebAudioで生成する自作の簡易音、初期状態OFF）
- エラーが起きても真っ白にならないエラー表示

## 4. 設定の変更

`js/config.js` の `CONFIG` オブジェクトで、EMA期間・RCI期間と注目水準・MACD設定・リスク%・参考リスクリワード・敵の強さなどを調整できます。
シナリオの追加は `js/scenarios.js` の `SCENARIO_DEFS` に1件追加するだけで、戦闘・ダンジョンに登場します。
練習問題・教材・敵・アイテム・実績の追加は `js/data.js` のデータ追加だけで反映されます。

## 5. 制限事項・未検証項目

- 開発環境での検証は Node.js 上のロジックテスト（全シナリオの生成検証、採点、全8章の通しプレイ、セーブ/ロード、ダンジョン）と、jsdom による画面遷移テスト（タイトル→キャラ選択→マップ→章→教え→実例→練習問題→戦闘→結果→勝利→各メニュー）で行いました。
- **実機ブラウザ（Chrome / Edge / iPhone Safari / Android Chrome）での目視確認は未実施です。** レイアウト崩れや細かな操作感は実機で確認してください。
- チャートは Canvas 描画コマンドを画像化して構図を確認しましたが、実機での見え方（フォント・高DPI）は未確認です。
- 効果音は WebAudio の簡易音のみで、BGMは実装していません。
- 人工データは意図した相場構造が出るように作っているため、本物の相場よりも波形が規則的です。
- 教材の内容は一般的なテクニカル分析と指定されたルールに基づいています。指定されていない部分を確定ルールとして説明しないよう配慮していますが、表現の修正が必要な場合は `js/data.js` と `js/scenarios.js` の文章を編集してください。
- 勝率・損益などの数値はゲーム内の学習記録であり、実際の収益を保証するものではありません。
